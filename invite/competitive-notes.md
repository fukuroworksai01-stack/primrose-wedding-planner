# Web招待状の競合調査と今回の改善

調査日：2026年9月21日。以下は公開ページで確認できるデザイン・導線を比較したもの。文面や画像を複製せず、この結婚式に必要な情報へ落とし込んだ。

| 参考 | 確認した点 | 今回の反映 |
| --- | --- | --- |
| [PIARY Web招待状](https://www.piary.jp/written_invitation/webinvitation/)・[デザイン一覧](https://www.piary.jp/written_invitation/webinvitation/design/) | ナチュラル、シンプル、クラシックなど印象別に選べる。写真・会場・回答が一つの導線にまとまる。 | 既存3案に、フォーマルな「シンプルレター」、写真重視の「フォトストーリー」、花とピンクの「ローズガーデン」を追加。 |
| [WedLink テンプレート](https://www.wedlink.jp/templates) | ゲスト側の見え方を確認しながらデザインを選べる。形式の違いがカードから分かる。 | 比較一覧に6案を常時表示し、各案の実ページへ1タップで移動。小画面では縦並びで読めるようにした。 |
| [Weddingday](https://weddingday.jp/) | 招待状の案内から出欠回答までモバイル上で進められる。 | 6案とも同じ回答フォームをページ内に設置。上部から「出欠を回答する」で直接移動できる。 |
| [ゼクシィの招待状ガイド](https://introduction.online.zexy.net/guide/invitation) | 作成後にふたり・式場で確認し、返信期限を設定してから共有する流れ。 | 比較リンクは送信不能なプレビューにし、未確定の回答期限や受付時刻を作らない。 |

確定日程は `wedding-details.js`（式場PDF転記）を全6案で共用する。会場写真は実際のお二人ではないため、必要な箇所に「会場イメージ」と明記する。プレビューでは出欠の確認操作まで試せるが送信はできない。公開用URLはプランナーのデザイン選択から生成し、回答は既存のGoogleスプレッドシート連携へ送る。
